# Academic Administration System

## 1. Project Overview

A web-based academic administration system designed
to centralize student and faculty record management,
reduce manual record-handling overhead, and improve
data consistency.

## 2. Project Objectives

- Centralize student records.
- Centralize faculty records.
- Reduce manual record management.
- Improve data consistency.

## 3. Functional Requirements

### Student Management
- Add student records.
- View student records.
- Search student records.
- Update student records.
- Delete student records.

### Faculty Management
- Add faculty records.
- View faculty records.
- Search faculty records.
- Update faculty records.
- Delete faculty records.

## 4. Non-Functional Requirements

- Data consistency
- Input validation
- Maintainability
- Usability
- Reliability

## 5. Proposed Technology Stack

- C#
- ASP.NET Core MVC
- SQL Server
- Entity Framework Core
- HTML
- CSS
- JavaScript

## 6. Project Scope

The system focuses on centralized student
and faculty record management.
